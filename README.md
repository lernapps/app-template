# app-template

Template for a new lernapps.net learning app: a minimal static, frontend-only app with the manifest `lernapps.json`, a license and thin CI that calls the shared workflows in [tooling](https://github.com/lernapps/tooling).

Nothing here yet (lernapps/.github#12). The plan is in [ORGANIZATION.md](https://github.com/lernapps/.github/blob/main/ORGANIZATION.md).
